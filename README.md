# MT-Portfolio

SSOT (Single Source of Truth) สำหรับโครงการจัดทำเอกสารประกอบการประเมินและความก้าวหน้าในตำแหน่ง ประจำปี พ.ศ. ๒๕๖๙

## เป้าหมายของโครงการ

จัดทำเอกสาร 2 ชุดหลัก

1. **เล่มใหญ่ — ผลการปฏิบัติงาน**  
   ใช้พิสูจน์ผลงาน ความรู้ความสามารถ ภารกิจ ผลลัพธ์ หลักฐาน และเอกสารอ้างอิง

2. **สรุปผลการปฏิบัติงานไม่เกิน ๓ หน้า**  
   ใช้ทำให้กรรมการเข้าใจคุณค่า จุดเด่น และ Personal Brand อย่างรวดเร็ว

## กลุ่มผู้อ่านหลัก

ผู้มีอำนาจพิจารณาระดับผู้บังคับบัญชาชั้นสูง อายุโดยประมาณ 50 ปีขึ้นไป และมีเวลาอ่านเอกสารของผู้สมัครแต่ละรายจำกัด

หลักการออกแบบจึงต้องเน้น:
- อ่านง่าย
- เห็นประเด็นเร็ว
- ผลลัพธ์มาก่อนเครื่องมือ
- หลักฐานรองรับทุกข้อ
- ไม่ overclaim
- ไม่สร้างตัวเลขหรือผลลัพธ์ที่พิสูจน์ไม่ได้

## Personal Brand Core

> **คิดเป็นระบบ ออกแบบงานได้ ใช้ข้อมูลและเทคโนโลยีพัฒนาองค์กร**

แกนการสื่อสาร:
- คิดวิเคราะห์ปัญหา
- ออกแบบ/ปรับปรุงกระบวนงาน
- จัดการและใช้ข้อมูล
- เลือกใช้เทคโนโลยีเป็นเครื่องมือ
- สร้างผลลัพธ์ที่เป็นประโยชน์ต่อราชการ
- ถ่ายทอดความรู้และพัฒนาคนเท่าที่มีหลักฐานจริง

## Repository Structure

- `docs/SSOT.md` — หลักการและข้อตกลงกลางของโครงการ
- `docs/document-structure.md` — โครงสร้างเอกสาร
- `docs/certificates/master-index.md` — ดัชนีใบประกาศและแนวทางนำไปใช้
- `evidence/` — หลักฐานที่จะเพิ่มภายหลัง
- `releases/` — ไฟล์ฉบับส่งจริงในอนาคต

## หลักการสำคัญ

- เทคโนโลยีไม่ใช่ตัวแบรนด์ แต่เป็นเครื่องมือของวิธีคิด
- งานต้นแบบเขียนเท่าที่สาธิตได้
- ทุกข้อความในสรุป ๓ หน้า ต้องมีหลักฐานในเล่มใหญ่
- ภาคผนวกใช้เป็นพื้นที่หลักฐานเต็ม เช่น ใบประกาศ หนังสือคำสั่ง ภาพกิจกรรม และภาพหน้าจอระบบ
- ใช้ถ้อยคำที่ตรวจสอบได้ เช่น “ช่วยลดขั้นตอน”, “ทำให้ข้อมูลพร้อมใช้”, “สนับสนุนการตัดสินใจ” แทนการใส่เปอร์เซ็นต์ที่ไม่มีหลักฐาน
