# MT-Portfolio

SSOT (Single Source of Truth) สำหรับโครงการจัดทำเอกสารประกอบการประเมินและความก้าวหน้าในตำแหน่ง ประจำปี พ.ศ. ๒๕๖๙

## เป้าหมายของโครงการ

จัดทำเอกสาร 3 ระดับที่ทำงานร่วมกัน

1. **One Page Report**  
   ใช้ทำให้กรรมการเห็นตัวตน คุณค่า และผลงานเด่นภายในประมาณ 30–60 วินาที และเกิดแรงจูงใจให้เปิดอ่านเอกสารส่วนถัดไป

2. **สรุปผลการปฏิบัติงานไม่เกิน ๓ หน้า**  
   ใช้ทำให้กรรมการเข้าใจคุณค่า จุดเด่น Personal Brand และผลสัมฤทธิ์สำคัญอย่างรวดเร็ว

3. **เล่มใหญ่ — ผลการปฏิบัติงาน**  
   ใช้พิสูจน์ผลงาน ความรู้ความสามารถ ภารกิจ ผลลัพธ์ หลักฐาน และเอกสารอ้างอิง

## กลุ่มผู้อ่านหลัก

ผู้มีอำนาจพิจารณาระดับผู้บังคับบัญชาชั้นสูง ซึ่งมีเวลาอ่านเอกสารของผู้สมัครแต่ละรายจำกัด และอาจไม่ได้คุ้นกับศัพท์เทคนิคด้าน IT/AI ในระดับลึก

หลักการออกแบบและการเขียนจึงต้องเน้น:
- อ่านง่าย เห็นประเด็นเร็ว
- ใช้ภาษาของผู้บริหาร มากกว่าภาษาของโปรแกรมเมอร์
- ผลลัพธ์และประโยชน์ต่อราชการมาก่อนเครื่องมือ
- หลักฐานรองรับทุกข้อ
- ไม่ overclaim
- ไม่สร้างตัวเลขหรือผลลัพธ์ที่พิสูจน์ไม่ได้
- ใช้ภาพและ key message ช่วยลดภาระการอ่าน

## Personal Brand Core

> **คิดวิเคราะห์ วางระบบ พัฒนาคน ใช้เทคโนโลยีอย่างเหมาะสม เพื่อขับเคลื่อนงานสู่ผลสัมฤทธิ์**

แกนการสื่อสาร:
- คิดวิเคราะห์ปัญหา
- ออกแบบ/ปรับปรุงกระบวนงาน
- จัดการและใช้ข้อมูล
- ลดงานซ้ำด้วยระบบอัตโนมัติเมื่อเหมาะสม
- สนับสนุนผู้บังคับบัญชาและภารกิจของหน่วย
- ศึกษาและประยุกต์ใช้ AI/เทคโนโลยีอย่างมีเหตุผล
- ถ่ายทอดความรู้และพัฒนาคนเท่าที่มีหลักฐานจริง
- พัฒนาตนเองอย่างต่อเนื่อง
- สร้างผลลัพธ์ที่เป็นประโยชน์ต่อราชการ

## Repository Structure

- `docs/SSOT.md` — หลักการและข้อตกลงกลางของโครงการ
- `docs/document-structure.md` — โครงสร้างเอกสาร
- `docs/drafts/one-page-report.md` — ทิศทางและเนื้อหา One Page Report
- `docs/certificates/master-index.md` — ดัชนีใบประกาศและแนวทางนำไปใช้
- `docs/evidence/` — บันทึกหลักฐานรายผลงาน
- `docs/implementation/` — Evidence Matrix และแผนดำเนินงาน
- `releases/` — ไฟล์ฉบับส่งจริงในอนาคต

## หลักการสำคัญ

- เทคโนโลยีไม่ใช่ตัวแบรนด์ แต่เป็นเครื่องมือของวิธีคิด
- งานต้นแบบเขียนเท่าที่สาธิตได้
- ทุกข้อความใน One Page และสรุป ๓ หน้า ต้องมีหลักฐานในเล่มใหญ่หรือ Primary Source ที่เหมาะสม
- ภาคผนวกใช้เป็นพื้นที่หลักฐานเต็ม เช่น ใบประกาศ หนังสือคำสั่ง ภาพกิจกรรม และภาพหน้าจอระบบ
- ใช้ถ้อยคำที่ตรวจสอบได้ เช่น “ช่วยลดขั้นตอน”, “ทำให้ข้อมูลพร้อมใช้”, “สนับสนุนการตัดสินใจ” แทนการใส่เปอร์เซ็นต์ที่ไม่มีหลักฐาน
