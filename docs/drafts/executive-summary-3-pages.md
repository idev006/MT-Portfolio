# Draft — สรุปผลการปฏิบัติงานไม่เกิน ๓ หน้า

> Working Draft — ใช้สำหรับประกอบการประเมิน พ.ศ. ๒๕๖๙

## หน้า ๑ — ตัวตน จุดเด่น และคุณค่าต่อหน่วยงาน

### ร.ต.อ. จิรัฎฐ์ธรณ์ จิตศิริ
รอง สว.ฝอ.๖ บก.อก.ภ.๖

> **คิดวิเคราะห์ วางระบบ พัฒนาคน ใช้เทคโนโลยีอย่างเหมาะสม เพื่อขับเคลื่อนงานสู่ผลสัมฤทธิ์**

ข้าฯ ยึดแนวคิดการทำงานแบบ Work Smart โดยมองว่าเทคโนโลยีควรถูกนำมาใช้เพื่อเพิ่มประสิทธิภาพและประสิทธิผล ลดขั้นตอนที่ไม่จำเป็น ทำให้กระบวนงานมีความกระชับ และช่วยให้บุคลากรสามารถนำเวลาไปใช้กับงานที่ต้องอาศัยการคิด วิเคราะห์ และการตัดสินใจมากขึ้น

### สมรรถนะหลัก
1. คิดวิเคราะห์และขยายโจทย์จากภารกิจจริง
2. วางระบบและออกแบบกระบวนงาน
3. พัฒนาคนและส่งเสริมการทำงานเป็นทีม
4. ประยุกต์ใช้ข้อมูลและเทคโนโลยีอย่างเหมาะสม

### ผลงานเด่น
- Dashboard 191 และระบบเตรียมข้อมูล
- Report 191 Processor
- IPB
- ฉลามบก

|---|---|---|

### กระบวนการทำงาน
**ปัญหา → วิเคราะห์ → ออกแบบกระบวนงาน → เลือกข้อมูล/เครื่องมือ → ดำเนินการ → ตรวจสอบ → ปรับปรุง**

เมื่อได้รับโจทย์จากผู้บังคับบัญชา ข้าฯ จะนำโจทย์มาวิเคราะห์ ออกแบบ วางแผน และพัฒนางานหรือระบบ โดยดำเนินการภายใต้คำแนะนำและการกำกับของผู้บังคับบัญชา

## หน้า ๓ — คน การเรียนรู้ คุณธรรม และการมีส่วนร่วมกับองค์กร

### การบริหารและพัฒนาผู้ใต้บังคับบัญชา
ข้าฯ ให้ความสำคัญกับการชี้แจงเป้าหมายและวัตถุประสงค์ของภารกิจก่อนมอบหมายงาน อธิบายกระบวนงาน แบ่งงานเป็นส่วนย่อย และสอนให้ผู้ปฏิบัติสามารถทำงานได้จริง โดยมุ่งให้ทีมสามารถทำงานร่วมกันและปฏิบัติงานทดแทนกันได้เมื่อมีความจำเป็น

มีหลักฐานประกอบด้านการกำชับวินัยและการพัฒนาผู้ใต้บังคับบัญชา โดยใช้หนังสือ “กำชับวินัย 1212” เป็นหลักฐานหลัก

### การพัฒนาตนเอง
พัฒนาความรู้ด้าน AI, Data, Network, IoT, PDPA, Cyber Safety และองค์ความรู้อื่นที่เกี่ยวข้อง โดยเลือกนำความรู้มาประยุกต์ใช้กับปัญหาและภารกิจจริงตามความเหมาะสม

### คุณธรรมและความน่าเชื่อถือ
ได้รับประกาศเกียรติคุณจากสำนักงานตำรวจแห่งชาติ ประจำปี พ.ศ. ๒๕๖๙ ด้านการประพฤติปฏิบัติดีเยี่ยมตามประมวลจริยธรรมข้าราชการตำรวจและหลักจรรยาบรรณของตำรวจ

### การมีส่วนร่วมกับองค์กร
มีหลักฐานภาพกิจกรรมด้านงานพระราชพิธี/พิธีสำคัญ งานจิตอาสา การพัฒนาหน่วยงาน กิจกรรมร่วมกับเพื่อนร่วมงาน ภารกิจตรวจติดตาม 191 และการสนับสนุนระบบ IT/ภาพ/เสียงสำหรับการประชุมและภารกิจของหน่วย

### Soft Closing
ข้าฯ มุ่งพัฒนาความสามารถในการคิดวิเคราะห์ วางระบบ พัฒนาคนและกระบวนงาน ตลอดจนเลือกใช้ข้อมูล ความรู้ และเทคโนโลยีอย่างเหมาะสม เพื่อให้เกิดผลสัมฤทธิ์และประโยชน์ต่อหน่วยงานและทางราชการอย่างต่อเนื่อง
