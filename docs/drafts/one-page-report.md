## ผลงานเด่นที่เสนอให้ใช้เป็น Hero Work

### 1. Dashboard 191 และระบบเตรียมข้อมูล
วิเคราะห์และออกแบบกระบวนการนำข้อมูลดิบจากศูนย์รับแจ้งเหตุฉุกเฉิน 191 มาประมวลผลและจัดโครงสร้างด้วยเครื่องมือที่พัฒนาขึ้น ก่อนนำไปแสดงผลใน Dashboard เพื่อสนับสนุนการติดตาม วิเคราะห์ และใช้ข้อมูลประกอบการปฏิบัติงาน

### 2. Report 191 Processor
พัฒนาเครื่องมือช่วยจัดทำรายงานประจำวันจากไฟล์ Excel หลายแหล่ง ลดขั้นตอนการประมวลผลซ้ำด้วยมือ โดยจากการใช้งานที่ผู้จัดทำยืนยัน กระบวนการเดิมใช้เวลาประมาณ 1 ชั่วโมง และสามารถลดลงเหลือไม่เกิน 1 นาที

### 3. ระบบ IPB
พัฒนา Web Application สำหรับจัดเก็บพิกัดและรายละเอียดของสถานที่หรือวัตถุต่าง ๆ ที่เกี่ยวข้องกับการวางแผนรักษาความปลอดภัย แสดงผลในรูปแบบแผนที่ และให้ผู้ใช้งานกำหนดเงื่อนไขการแสดงพิกัดตามความต้องการ

### 4. ฉลามบก

## มิติด้านคน
- ชี้แจงเป้าหมาย วัตถุประสงค์ และกระบวนงานก่อนมอบหมาย
- สอนให้ผู้ใต้บังคับบัญชาเข้าใจและสามารถปฏิบัติงานได้
- ส่งเสริมการทำงานเป็นทีมและการปฏิบัติงานทดแทนกันได้
- มีหลักฐานหนังสือกำชับวินัยและการพัฒนาผู้ใต้บังคับบัญชา

## มิติด้านคุณธรรมและความน่าเชื่อถือ
ได้รับประกาศเกียรติคุณจากสำนักงานตำรวจแห่งชาติ ประจำปี พ.ศ. ๒๕๖๙ ในด้านการประพฤติปฏิบัติดีเยี่ยมตามประมวลจริยธรรมข้าราชการตำรวจและหลักจรรยาบรรณของตำรวจ
