# MT-Portfolio — Creative Production Workflow v2

## Decision
Use **Art Director-led hybrid production**, not a fixed `design-as-code` page renderer. Do not discard code: use it to protect factual integrity, Thai typography, source traceability, sizing, export quality and repeatability.

## Nonnegotiable safeguards
1. Exact owner-approved claims from `content-lock.json`; no invented persons, data, timings, percentages, awards, events or system screenshots.
2. Evidence labels and provenance from `evidence-register.md`; conceptual graphics are never presented as evidentiary photographs.
3. Three independently composed A4 portrait pages, 2480×3508 minimum, each shown inline; no logos or placeholders; portrait slot on P1 empty at height:width 4:3.
4. Thai text is actual typeset text, visually and semantically checked; name, rank, unit and numerals meet current approved exceptions.

## Creative freedoms
- Choose bespoke visual hierarchy, editorial collage/mosaic, scale contrast, photomontage, process diagrams, and impactful storytelling separately for each page.
- Navy/gold/silver remain identity anchor; varied tonal distribution is welcome.
- Header/content/footer percentages, card count, grid boundaries, and per-case visual quotas are **advisory** only.
- May use illustration tools for clearly non-evidentiary art. Do not generate Thai lettering inside painted images; composite verified copy through real font typesetting.

## Page briefs
- P1: human identity, actual work method, two dominant owner-confirmed outcomes (191 report and cooperative >200 pages), no 191 dashboard here.
- P2: five distinct work cases including SHARK, IPB (both prior unit), Dashboard 191, reporting from existing radio records, and support work; diagrams must not invent chart values.
- P3: separate actual teaching/knowledge transfer/discipline from conceptual managerial goals. Clearly label MTSecurity / AI CCTV / Computer Vision as study/prototype. Include learning and honours only in owner-approved copy; original certificate validation pending.

## Production sequence
1. Ingest latest locked content + genuine image assets and register hashes/authorized usage.
2. Sketch three separate compositions; critique against visual storytelling goals and locked evidence status.
3. Produce imagery and page artwork without fake evidence; place copy with actual Thai font.
4. Automated preflight for strings, numerals, source hashes, dimensions, missing elements, safety and export.
5. Inspect each page at print scale; do independent Thai proofreading; deliver as PRODUCTION CANDIDATE until owner art approval and evidence release gates pass.

## Legacy
`make_portfolio.py` is **historical renderer only**. Do not remove it, as audit history can aid regression comparison. Never use the previously rejected images or triptych as final artwork.

## Owner cancellation — 2026-10-17 (supersedes hybrid design approach)
Design-as-Code is **cancelled** as a design/authoring methodology for this three-page project. AI Art Direction governs creative decisions. Do not create or reuse page layouts through Python-drawn sections/cards, programmatic geometry, or template-first generation. Source content and evidence controls remain binding; optional code may only validate facts, file dimensions, font/Thai text, provenance, and export. Generate genuine page artwork and use real Thai typesetting without fabricated evidence. The previous hybrid method is historical only.
