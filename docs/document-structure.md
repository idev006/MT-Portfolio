# Document Structure

## A. เล่มใหญ่ — ผลการปฏิบัติงาน

1. ปกหน้า
2. One Page Executive Profile / One Page Report
3. คำนำ
4. สารบัญ
5. Executive Summary / สรุปผลสัมฤทธิ์สำคัญ
6. ข้อมูลส่วนบุคคล / คุณวุฒิ / การศึกษาอบรม
7. ความรู้ ความสามารถ
8. ประวัติการดำรงตำแหน่ง
9. ผลงานดีเด่นเป็นที่ประจักษ์หรือได้รับประกาศเกียรติคุณ (ระดับ ตร., บช., บก., กก.)
10. ภารกิจพิเศษนอกเหนือจากภารกิจตามหน้าที่รับผิดชอบ (ระดับ ตร., บช., บก., กก.)
11. ภารกิจตามหน้าที่รับผิดชอบ
12. การบริหาร กำกับดูแล และพัฒนาผู้ใต้บังคับบัญชา
13. งานริเริ่ม / งานศึกษา / ระบบต้นแบบ
14. การศึกษาอบรมและการพัฒนาตนเอง
15. กิจกรรมและการมีส่วนร่วมกับองค์กร
16. ความเชื่อมโยงกับภารกิจ กฎหมาย แผน และนโยบาย
17. บทสรุป Personal Brand / คุณค่าต่อองค์กร
18. ภาคผนวก
19. อภิธานศัพท์
20. เอกสารอ้างอิง

> หมายเหตุ: หัวข้อราชการที่มีถ้อยคำกำหนดไว้ โดยเฉพาะหัวข้อ 3–6 ตามแบบประเมิน ให้รักษาถ้อยคำและลำดับเดิม ใช้หัวข้อย่อยเพิ่มเติมแทนการเปลี่ยนชื่อหัวข้อหลัก

## B. One Page Report

วัตถุประสงค์: ให้กรรมการเห็นภาพรวมภายในประมาณ 30–60 วินาที

องค์ประกอบ:
- ชื่อ / ยศ / ตำแหน่ง
- Brand Core
- แนวคิด Work Smart
- ผลงานเด่น 3–4 รายการ
- มิติด้านคนและการกำกับดูแล
- มิติคุณธรรม/ความน่าเชื่อถือ
- สมรรถนะหลัก
- ข้อความปิดที่สะท้อนคุณค่าต่อองค์กร

## C. สรุปผลการปฏิบัติงานไม่เกิน ๓ หน้า

### หน้า ๑ — ตัวตน จุดเด่น และคุณค่าต่อหน่วยงาน
- ชื่อ / ตำแหน่ง
- แนวทางการปฏิบัติงาน
- Brand Core
- 4 สมรรถนะหลัก: คิดวิเคราะห์ / วางระบบและออกแบบกระบวนงาน / พัฒนาคน / ใช้ข้อมูลและเทคโนโลยี
- ผลงานเด่น 3–4 รายการ

### หน้า ๒ — ผลงานจริงและผลที่เกิดกับราชการ
ตาราง:
**ปัญหา / ความต้องการ | แนวทางที่ดำเนินการ | ผลต่อการปฏิบัติราชการ**

เน้น:
- ฉลามบก
- IPB
- Dashboard 191
- Report 191 Processor / Data Processing
- ข้อมูลครุภัณฑ์วิทยุ

รูปแบบการทำงาน:
**ปัญหา → วิเคราะห์ → ออกแบบกระบวนงาน → เลือกข้อมูล/เครื่องมือ → ดำเนินการ → ตรวจสอบ → ปรับปรุง**

### หน้า ๓ — คน การเรียนรู้ จิตสาธารณะ และ Soft Closing
- การชี้แจงเป้าหมาย / มอบหมาย / สอนงาน / ทำงานทดแทนกันได้
- การกำชับวินัยและการพัฒนาผู้ใต้บังคับบัญชา
- การพัฒนาตนเองจากสถาบันที่น่าเชื่อถือ
- กิจกรรมองค์กรและจิตสาธารณะ
- Soft Closing
- ปิดด้วย Brand Core

## D. โครงมาตรฐานของแต่ละผลงาน

**ปัญหา/ความต้องการ → สิ่งที่ดำเนินการ → บทบาทของข้าฯ → ความท้าทาย → ผลลัพธ์/ประโยชน์ → แนวทางประยุกต์/ต่อยอด → หลักฐาน**

## Visual Principle

- A4 แนวตั้ง
- TH Sarabun New เป็นหลัก
- เนื้อหาหลักประมาณ 16 pt
- หัวข้อ 18–20 pt หรือมากกว่าตามระดับ
- ตัวอักษรใหญ่ อ่านง่ายสำหรับกรรมการอาวุโส
- ใช้ช่องว่างช่วยแยกกลุ่มข้อมูล
- ไม่ใช้ตารางหนาแน่นเกินไป
- ภาพในสรุป ๓ หน้าเพียง 3–5 ภาพรวมทั้งชุด
- ภาพกิจกรรมจำนวนมากให้ไปเล่มใหญ่/ภาคผนวก
- หลักฐานผลงานต้องมีน้ำหนักมากกว่าภาพกิจกรรม
