# Document Structure

## A. เล่มใหญ่ — ผลการปฏิบัติงาน

โครงสร้างที่แนะนำ:

1. ปกหน้า
2. One Page Executive Profile / One Page Report
3. คำนำ
4. สารบัญ
5. สรุปผลสัมฤทธิ์สำคัญ (Executive Summary)
6. ข้อมูลส่วนบุคคล / คุณวุฒิ / การศึกษาอบรม
7. ความรู้ ความสามารถ
8. ประวัติการดำรงตำแหน่ง
9. ผลงานดีเด่นเป็นที่ประจักษ์หรือได้รับประกาศเกียรติคุณ
10. ภารกิจพิเศษนอกเหนือจากภารกิจตามหน้าที่รับผิดชอบ
11. ภารกิจตามหน้าที่รับผิดชอบ
12. การบริหาร กำกับดูแล และพัฒนาผู้ใต้บังคับบัญชา
13. งานริเริ่ม / งานศึกษา / ระบบต้นแบบ
14. การศึกษาอบรมและการพัฒนาตนเอง
15. ความเชื่อมโยงกับภารกิจ กฎหมาย แผน และนโยบาย
16. บทสรุป Personal Brand / คุณค่าที่มีต่อองค์กร
17. ภาคผนวก
18. อภิธานศัพท์
19. เอกสารอ้างอิง

> หมายเหตุ: หัวข้อราชการที่มีถ้อยคำกำหนดไว้ ให้รักษาถ้อยคำเดิมและใช้หัวข้อย่อยเพิ่มเติมแทนการเปลี่ยนชื่อหัวข้อหลัก

## B. สรุปผลการปฏิบัติงานไม่เกิน ๓ หน้า

### หน้า ๑ — ตัวตน จุดเด่น และคุณค่าต่อหน่วยงาน
- ชื่อ / ตำแหน่ง
- แนวทางการปฏิบัติงาน
- Brand Core
- 4 สมรรถนะหลัก: คิดวิเคราะห์ / ออกแบบกระบวนงาน / ข้อมูล / เทคโนโลยี
- ผลงานเด่น 3–4 รายการ

### หน้า ๒ — ผลงานจริงและผลที่เกิดกับราชการ
ตาราง:
**ปัญหา / ความต้องการ | แนวทางที่ดำเนินการ | ผลต่อการปฏิบัติราชการ**

เน้น:
- ฉลามบก
- IPB
- Dashboard 191
- ข้อมูลครุภัณฑ์วิทยุ
- Automation / Data Processing

แสดงรูปแบบการทำงาน:
**ปัญหา → วิเคราะห์ → ออกแบบกระบวนงาน → เลือกข้อมูล/เครื่องมือ → ดำเนินการ → ตรวจสอบ → ปรับปรุง**

### หน้า ๓ — คน การเรียนรู้ จิตสาธารณะ และ Soft Closing
- การ Brief / Coaching / กำกับดูแล
- การพัฒนาตนเองจากสถาบันที่น่าเชื่อถือ
- กิจกรรมองค์กรและจิตสาธารณะ
- Soft Closing
- ปิดด้วย Brand Core

## Visual Principle

กรรมการเป้าหมายมีเวลาอ่านจำกัด จึงต้อง:
- ตัวอักษรใหญ่ อ่านง่าย
- ใช้ช่องว่างช่วยแยกกลุ่มข้อมูล
- ใช้หัวข้อชัด
- ภาพในสรุป ๓ หน้าเพียง 3–5 ภาพรวมทั้งชุด
- ภาพกิจกรรมจำนวนมากให้ไปเล่มใหญ่/ภาคผนวก
- หลักฐานผลงานต้องมีน้ำหนักมากกว่าภาพกิจกรรม
