# Report 191 Processor — โปรแกรมสร้างรายงาน 191 ประจำวัน

## สถานะ
ผลงานใช้งานจริง / ผลงานเชิงประจักษ์

## ปัญหาจากการปฏิบัติงาน
ในแต่ละวัน เจ้าหน้าที่ต้องดาวน์โหลดไฟล์ข้อมูลการรับแจ้งเหตุ 191 จากกลุ่ม LINE จำนวน 9 ไฟล์ จาก 9 ศูนย์ฯ แล้วนำข้อมูลมาประมวลผลด้วย Microsoft Excel เพื่อจัดทำรายงานประจำวัน

กระบวนการเดิมใช้เวลาประมาณ 1 ชั่วโมงต่อรอบ และมีความเสี่ยงต่อความผิดพลาดจากการรวม คัดลอก หรือประมวลผลข้อมูลด้วยมือ

## แนวทางที่ดำเนินการ
พัฒนาโปรแกรม **Report 191 Processor** เพื่อช่วยนำเข้าไฟล์ Excel หลายไฟล์ ประมวลผล และสร้างรายงานประจำวันให้อยู่ในรูปแบบที่พร้อมใช้งาน

จากหน้าจอโปรแกรมมีองค์ประกอบสำคัญ เช่น
- เลือก/ลากไฟล์ Excel หลายไฟล์เข้าสู่ระบบ
- แสดงรายการไฟล์ที่เลือก
- ประมวลผลไฟล์แบบชุด
- แสดงความคืบหน้าและบันทึกการทำงาน
- สร้างรายงานอัตโนมัติ
- แยกส่วนประมวลผลและสร้างรายงาน

## ผลลัพธ์ที่ผู้จัดทำยืนยัน
- ข้อมูลต้นทาง: 9 ไฟล์จาก 9 ศูนย์ฯ
- เวลากระบวนการเดิมโดยเจ้าหน้าที่: ประมาณ 1 ชั่วโมง
- โปรแกรมสามารถสร้างรายงานประจำวันได้ภายในเวลาไม่เกิน 1 นาที

## คุณค่าต่อหน่วยงาน
- ลดระยะเวลาการจัดทำรายงานประจำวันอย่างมีนัยสำคัญ
- ลดขั้นตอนการรวมและประมวลผลข้อมูลด้วยมือ
- ลดโอกาสเกิดความผิดพลาดจากการคัดลอกหรือคำนวณข้อมูล
- ทำให้รายงานพร้อมใช้ได้รวดเร็วขึ้น
- ช่วยให้เจ้าหน้าที่นำเวลาไปใช้กับงานที่ต้องอาศัยวิจารณญาณมากขึ้น

## Brand Proof
ผลงานนี้สะท้อน Brand Core โดยตรง:

> **คิดเป็นระบบ ออกแบบงานได้ ใช้ข้อมูลและเทคโนโลยีพัฒนาองค์กร**

เพราะเริ่มจากปัญหากระบวนงานจริง วิเคราะห์ขั้นตอนที่ใช้เวลามากและเสี่ยงผิดพลาด แล้วออกแบบเครื่องมือเพื่อเปลี่ยนงานซ้ำให้เป็นกระบวนการอัตโนมัติ

## ความสัมพันธ์กับ Dashboard 191
ผลงานนี้ควรแยกจากโปรแกรมเตรียมข้อมูลสำหรับ Dashboard 191 แม้จะอยู่ในชุดงาน 191 เดียวกัน

- **Report 191 Processor** = เน้นสร้างรายงานประจำวันจากไฟล์ Excel 9 ศูนย์ฯ
- **MT191Dashboard Batch Tools** = เน้นทำความสะอาด แปลง และเตรียมข้อมูลสำหรับ Dashboard/Looker Studio และการวิเคราะห์เชิงพื้นที่

## หลักการนำเสนอใน Portfolio
ควรเล่าในรูปแบบ:
**ปัญหา → วิเคราะห์ขั้นตอนเดิม → พัฒนาโปรแกรม → เวลาเดิมประมาณ 1 ชั่วโมง → เหลือไม่เกิน 1 นาที → ลดความเสี่ยงผิดพลาด**

ตัวเลข “ประมาณ 1 ชั่วโมง” และ “ไม่เกิน 1 นาที” เป็นข้อมูลที่ผู้จัดทำยืนยันจากการใช้งานจริง จึงสามารถใช้ในเอกสารได้ แต่ควรหลีกเลี่ยงการแปลงเป็นเปอร์เซ็นต์เว้นแต่ต้องการคำนวณและมีหลักฐานรองรับเพิ่มเติม
