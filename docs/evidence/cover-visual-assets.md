## Recommended Visual Hierarchy

### One Page Report
1. Hero portrait: `ภาพธี.jpg`
2. Background/secondary institutional image: เลือก 1 ภาพจากอาคารหอประชุม
3. Accent / identity element: ใช้ภาพอนุสาวรีย์ 1 ภาพแบบ subtle crop หรือ watermark

### Cover
- Primary concept: ภาพผู้นำเสนอ + อาคารหอประชุม + motif อนุสาวรีย์
- หลีกเลี่ยงการใส่ภาพทั้ง 6 ภาพพร้อมกัน
- ใช้ 2–3 ภาพต่อ composition เพื่อให้ดูเป็นทางการและไม่แน่นเกินไป

## Evidence Rule
- ภาพผู้นำเสนอ = ภาพประจำตัว/ผู้จัดทำ
- ภาพอาคารและอนุสาวรีย์ = institutional context / identity
- ห้ามใช้ภาพอาคารหรืออนุสาวรีย์เป็นหลักฐานว่าผู้จัดทำเป็นผู้สร้าง ดำเนินการ หรือมีส่วนร่วมในโครงการก่อสร้าง
