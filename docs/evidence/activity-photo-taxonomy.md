# Activity Photo Taxonomy — การจัดกลุ่มภาพกิจกรรม

## หลักการ
ภาพกิจกรรมใช้เพื่อเสริมมิติด้านวินัย จิตสาธารณะ การมีส่วนร่วมกับองค์กร การทำงานร่วมกับผู้อื่น และความรับผิดชอบต่อหน้าที่

ภาพกิจกรรมไม่ควรมีน้ำหนักมากกว่าผลงานเชิงประจักษ์และผลงานพัฒนาระบบ แต่ควรใช้เป็นหลักฐานประกอบด้านพฤติกรรมและการมีส่วนร่วมในองค์กร

## กลุ่มภาพหลัก

### 1. กิจกรรมงานพระราชพิธี / พิธีสำคัญของทางราชการ
ตัวอย่าง:
- วันคล้ายวันสวรรคตสมเด็จพระนเรศวรมหาราช
- วันยุทธหัตถี
- วันสวรรคตพระบาทสมเด็จพระจุลจอมเกล้าเจ้าอยู่หัว
- พิธีสำคัญของหน่วยงานและของทางราชการ

คุณค่าที่สื่อ:
- ความมีวินัย
- การรักษาแบบธรรมเนียม
- การมีส่วนร่วมในภารกิจขององค์กร
- ความรับผิดชอบต่อหน้าที่และสถาบัน

### 2. กิจกรรมงานจิตอาสา
ตัวอย่าง:
- กิจกรรมจิตอาสาพัฒนา
- การช่วยเหลือประชาชน
- กิจกรรมสาธารณประโยชน์
- การแจกสิ่งของ/อาหาร หรือกิจกรรมกับชุมชน

คุณค่าที่สื่อ:
- จิตสาธารณะ
- ความเสียสละ
- การมีส่วนร่วมกับประชาชนและชุมชน
- ภาพของข้าราชการที่พร้อมสนับสนุนภารกิจส่วนรวม

### 3. กิจกรรมพัฒนาหน่วยงาน
ตัวอย่าง:
- ทำความสะอาดพื้นที่
- ปรับปรุงภูมิทัศน์
- พัฒนาพื้นที่รอบอาคาร
- กิจกรรม 5ส. หรือกิจกรรมดูแลสถานที่ทำงาน

คุณค่าที่สื่อ:
- ลงมือทำจริง
- ความรับผิดชอบต่อพื้นที่และทรัพยากรของหน่วย
- การทำงานร่วมกับทีม
- วัฒนธรรมการพัฒนาอย่างต่อเนื่อง

### 4. กิจกรรมกับเพื่อนร่วมงาน / การมีส่วนร่วมในองค์กร
ตัวอย่าง:
- กิจกรรมรับประทานอาหารร่วมกัน
- งานส่งผู้บังคับบัญชา
- กิจกรรมกีฬา
- กิจกรรมสร้างความสัมพันธ์ภายในหน่วย
- งานประชุม/พบปะภายในองค์กร

คุณค่าที่สื่อ:
- มนุษยสัมพันธ์
- การทำงานร่วมกับผู้อื่น
- การมีส่วนร่วมกับทีม
- ความผูกพันและวัฒนธรรมองค์กร

## แนวทางใช้ในเอกสาร

### สรุป 3 หน้า
ใช้เพียง 1–2 ภาพที่สื่อ “คน” และ “องค์กร” ชัดที่สุด โดยไม่เบียดพื้นที่ผลงานหลัก

### เล่มใหญ่
สามารถมีหน้า “กิจกรรมและการมีส่วนร่วมกับองค์กร” แบ่งเป็น 4 กลุ่มข้างต้น ใช้ภาพคัดเลือกแบบ collage/editorial ไม่ใช้ภาพจำนวนมากเท่า ๆ กันจนรบกวนการอ่าน

### ภาคผนวก
เก็บภาพเพิ่มเติมหรือชุดภาพเต็มสำหรับกิจกรรมที่ต้องการหลักฐานประกอบ

## หลักคัดภาพ
- เลือกภาพที่เห็นการมีส่วนร่วมจริง ไม่ใช่เพียงยืนถ่ายรูป
- เลือกภาพที่มีบริบทชัดว่าเป็นกิจกรรมประเภทใด
- หลีกเลี่ยงภาพซ้ำเหตุการณ์เดียวกันหลายภาพในเนื้อหาหลัก
- ให้แต่ละภาพตอบคำถามว่า “ภาพนี้ช่วยบอกอะไรเกี่ยวกับตัวบุคคล”
- ใช้คำบรรยายสั้น เน้นกิจกรรมและบทบาท ไม่ใช้ภาษายกย่องเกินจริง
