## วัตถุประสงค์
พัฒนาโปรแกรมเดสก์ท็อปสำหรับใส่ข้อความและโลโก้ลงบนไฟล์ PDF และรูปภาพ โดยรองรับงานหลายไฟล์แบบ Batch และมี Preview ก่อนประมวลผล

## ความสามารถที่ยืนยันจาก Repository
- Desktop application สำหรับ Windows และ Linux
- ใช้ Python 3.12
- GUI ใช้ PySide6
- รองรับ PDF และรูปภาพ png/jpg/jpeg
- ผู้ใช้เพิ่ม Text, Logo หรือ Text+Logo ได้หลายรายการ
- แต่ละรายการตั้งค่าได้อิสระ
- รองรับตำแหน่งมาตรฐาน 9 จุด
- รองรับการลากวางตำแหน่งอิสระบน Preview
- ตำแหน่งแบบอิสระเก็บเป็นเปอร์เซ็นต์ของหน้า ไม่ผูกกับพิกเซลหน้าจอ
- เลือกหน้า Preview ของ PDF ได้
- ซูมเข้า/ออกและ Fit Preview ได้
- รองรับ Batch Processing หลายไฟล์
- เลือก Input Folder แบบ recursive พร้อมจำกัดความลึกได้
- ตั้ง Output Folder แยกจาก Input
- รักษาโครงสร้าง Subfolder ได้
- กำหนดจำนวน Workers สำหรับประมวลผลพร้อมกันได้
- รองรับการกรองหน้า PDF ตามคำหรือ Regex
- บันทึก/โหลด Overlay Settings ด้วย TOML
- มี Recent Settings / Default Settings
- มี Progress, Cancel, Resume และ Error Isolation
- ใช้ temporary output และ atomic replace
- มี Queue table แสดง input, page count, output, progress, status, error
