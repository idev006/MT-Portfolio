# MT191Dashboard — โปรแกรมเตรียมข้อมูลสำหรับ Dashboard 191

## บทบาทของโปรแกรม
โปรแกรมนี้เป็นเครื่องมือเตรียมข้อมูลก่อนนำไปใช้ใน Google Looker Studio สำหรับ Dashboard การรับแจ้งเหตุฉุกเฉิน 191 ของตำรวจภูธรภาค 6

## หลักฐานจากหน้าจอโปรแกรม
หน้าจอแสดงโมดูลหลัก ได้แก่
- Batch Process
- Stamp Row Numbers
- Apply Is Race
- Stamp GUID
- Geo Lookup

### Batch Process
รับโฟลเดอร์ไฟล์ Excel ต้นทางหลายไฟล์ แล้วอ่าน/รวม/ปรับรูปแบบข้อมูลให้อยู่ในโครงสร้างเดียวกัน ก่อนสร้าง output_all.xlsx

ตัวอย่างจากหน้าจอ:
- ประมวลผลไฟล์สำเร็จ 9 ไฟล์
- รวมข้อมูล 6,528 แถว
- มีขั้นตอน Data Cleaning หลายฟิลด์ เช่น closure_time, details, incident, incident_location

### Geo Lookup
นำ latitude/longitude จากข้อมูล Excel ไปทำ Spatial Join กับข้อมูลเชิงพื้นที่ เพื่อเติมข้อมูลพื้นที่ปกครอง เช่น ตำบล อำเภอ จังหวัด

ตัวอย่างจากหน้าจอ:
- valid 6,528
- invalid/missing 0
- matched 6,526 จาก 6,528
- ใช้เวลาประมาณ 14.3 วินาทีในตัวอย่างที่แสดง

## กระบวนการภาพรวม
Excel ดิบจากศูนย์ 191
→ Batch Process / Data Cleaning
→ การกำหนดเลขแถวและ GUID
→ การคัดกรอง/ประทับตราเหตุเฉพาะประเด็น
→ Geo Lookup / Spatial Join
→ output_all.xlsx
→ Google Looker Studio Dashboard

## คุณค่าที่ควรสื่อใน Portfolio
ผลงานนี้ไม่ใช่เพียงการสร้าง Dashboard แต่สะท้อนการออกแบบ data pipeline ตั้งแต่ข้อมูลดิบจนถึงข้อมูลพร้อมวิเคราะห์

## ข้อควรระวัง
- ตัวเลขเวลา 14.3 วินาทีและจำนวน 6,528 แถวเป็นเพียงตัวอย่างจากหน้าจอหนึ่งรอบการประมวลผล ไม่ควรนำไปอ้างเป็นค่าเฉลี่ยหรือ SLA
- ไม่ควรกล่าวว่าแม่นยำ 100% แม้ตัวอย่างจะแสดง invalid/missing = 0
- ควรใช้คำว่า “ช่วยลดขั้นตอน”, “ทำให้ข้อมูลพร้อมใช้”, “ประมวลผลข้อมูลจำนวนมากอย่างเป็นระบบ” จนกว่าจะมีผลเปรียบเทียบก่อน/หลังที่ตรวจสอบได้
