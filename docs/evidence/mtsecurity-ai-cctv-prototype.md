# MTSecurity — AI CCTV Security System

## สถานะ
โครงการต้นแบบ / งานศึกษาและพัฒนา

## แหล่งหลักฐาน
- Repository: idev006/MTSecurity
- Repository เป็น Public และใช้ภาษา Python เป็นภาษาหลัก
- คำอธิบาย repository: "กล้อง AI จำนวน 10 ตัว รองรับเว็บแคม"
- ภาพสรุปโครงการที่ผู้จัดทำส่งให้ แสดงแนวคิดระบบ AI CCTV แบบ Real-time, Dashboard และการแจ้งเตือน

## แนวคิดของโครงการ
ศึกษาการประยุกต์ใช้ AI/Computer Vision กับระบบกล้องวงจรปิด เพื่อให้ระบบสามารถวิเคราะห์ภาพจากกล้องและจำแนกเหตุการณ์ที่กำหนดไว้ในต้นแบบ พร้อมแสดงสถานะผ่าน Dashboard

## ความสามารถที่ปรากฏในเอกสาร/ภาพสรุปต้นแบบ
- Real-time AI detection
- รองรับหลายกล้อง
- RTSP stream / USB webcam
- Zone & Rule Builder
- Live Dashboard
- Event Management
- Notification
- User Management
- แนวคิดตรวจจับเหตุการณ์ เช่น Intrusion, Loitering, Abandoned Object, Crowd, Crouching, Falls

## เทคโนโลยีที่ระบุในภาพสรุป
- Backend: Python, FastAPI, SQLAlchemy, OpenVINO, OpenCV
- Frontend: Vue 3, TypeScript, Pinia, DaisyUI, Tailwind CSS
- Protocol: WebSocket
- Database: SQLite (async)

## มุมสำหรับ Portfolio
โครงการนี้ควรนำเสนอเป็น **ต้นแบบที่สะท้อนความสามารถด้านการคิดวิเคราะห์และออกแบบระบบ** ไม่ใช่ผลงานใช้งานจริงของหน่วยงาน เว้นแต่มีหลักฐานการนำไปใช้งานจริงเพิ่มเติม

ข้อความแนะนำ:

> ศึกษาและพัฒนาระบบต้นแบบกล้องวงจรปิดอัจฉริยะโดยประยุกต์ใช้ AI และ Computer Vision เพื่อทดลองวิเคราะห์ภาพจากกล้องแบบ Real-time ตรวจจับเหตุการณ์ตามเงื่อนไขที่กำหนด และแสดงผลผ่าน Dashboard โดยออกแบบให้รองรับการเชื่อมต่อกล้องหลายแหล่งและการแจ้งเตือนเหตุการณ์ เพื่อศึกษาความเป็นไปได้ในการนำเทคโนโลยีมาช่วยงานเฝ้าระวังและความปลอดภัย

## Brand Proof
สนับสนุน Brand Core:

> **คิดเป็นระบบ ออกแบบงานได้ ใช้ข้อมูลและเทคโนโลยีพัฒนาองค์กร**

โดยสะท้อนความสามารถในการ:
- ออกแบบสถาปัตยกรรมระบบ
- เชื่อม Backend / Frontend / Video Stream / AI Inference
- กำหนดเงื่อนไขและกฎของเหตุการณ์
- ออกแบบ Dashboard สำหรับผู้ใช้งาน
- คิดเชิงระบบมากกว่าการทดลองโมเดล AI แยกส่วน

- ไม่ใช้คำว่า “ใช้งานจริงได้ทันที”, “แม่นยำ”, “พร้อมใช้งานจริง” ใน Portfolio หากยังไม่มีหลักฐานทดสอบ/ใช้งานจริง
- จำนวนกล้องและฟังก์ชันต่าง ๆ ควรเขียนตามสิ่งที่สามารถสาธิตหรือพิสูจน์จากระบบได้
- คำโฆษณาในภาพสรุปไม่ถือเป็นหลักฐานผลสัมฤทธิ์โดยตัวมันเอง
