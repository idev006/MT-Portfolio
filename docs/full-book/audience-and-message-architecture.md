# Audience & Message Architecture — เล่มผลการปฏิบัติราชการ ๒๕๖๙
สถานะ: **ข้อเสนอเพื่ออนุมัติ (PROPOSED)**; ใช้ร่วมกับ communication-blueprint.md

## ผู้รับสาร / สถานการณ์การอ่าน
1. **ผู้บริหารผู้พิจารณา**: เวลาอ่านจำกัด ต้องเห็นหน้าที่จริง จุดเด่น ผลสัมฤทธิ์ และความเหมาะสมต่อความรับผิดชอบสูงขึ้นโดยไม่ต้องเข้าใจศัพท์เทคนิค
2. **ผู้ตรวจรายละเอียด/กรรมการ**: ตรวจลำดับตำแหน่ง ช่วงเวลา หัวข้อบังคับ ตัวเลข บทบาทจริง และหลักฐานย้อนหลังได้
3. **ผู้ประสานงานเอกสาร**: ต้องค้นเอกสารแนบและคำอธิบายภาพได้โดยไม่ต้องถามผู้จัดทำซ้ำ
บุคลิกที่ออกแบบเป็น **พฤติกรรมการอ่านที่คาดการณ์** ไม่ใช่ข้ออ้างว่าเราทราบทัศนคติส่วนตัวของกรรมการ

## จุดมุ่งหมาย
รับรู้ → เข้าใจ → เห็นผล → เชื่อมั่น → ประเมินความพร้อม
ไม่ตั้งเป้าให้หนังสือ “ชนะด้วยความสวย” แต่ให้สื่อข้อเท็จจริงและความเหมาะสมผ่านหลักฐาน

## Master message (เสนอ)
“ข้าราชการตำรวจที่เข้าใจภารกิจ มีความรับผิดชอบ คิดและแก้ปัญหาอย่างเป็นระบบ และนำข้อมูล เทคโนโลยี ตลอดจนทักษะการสื่อสารมาสนับสนุนการปฏิบัติราชการให้เกิดประโยชน์อย่างเป็นรูปธรรม”
**หมายเหตุ:** เป็นทิศทางการเขียน ไม่ใช่ข้อความยืนยันทุกองค์ประกอบโดยปราศจากหลักฐาน

## Message pillars
- **ความรับผิดชอบต่อหน้าที่**: งานอำนวยการ/เทคนิค/โสตฯ/ติดตามศูนย์ ๑๙๑ ที่ทำจริง
- **คิดเป็นระบบและสร้างผลสัมฤทธิ์**: รายงาน ๑๙๑, การเตรียมข้อมูล, Excel/Macro, เอกสาร PDF ตามหลักฐาน
- **ความสามารถในการสนับสนุนงานหลายด้าน**: งานข้ามฝ่าย การจัดทำข้อมูล และการวิเคราะห์
- **สื่อสารเพื่อองค์กรและประชาชน**: Infographic, One-page, Poster, LINE Sticker, LINE Bot; ไม่อ้างผลการใช้งานถ้าไม่มี
- **บุคลากร วินัย จิตสาธารณะ และการเรียนรู้**: บทบาทจริง/หลักฐานการเข้าร่วม ไม่ขยายความเกินจริง

## Narrative specification
ทุกกรณีศึกษาหลัก: ความต้องการ → ผลกระทบต่องาน → วิธีดำเนินการ → บทบาทเฉพาะ → ผลที่ตรวจสอบได้ → ประโยชน์ → หลักฐาน
ทุกบท: key message 1 ประโยค + กรณีที่ชัด 1–3 รายการ + จุดอ้างอิง
**ห้าม** แสดงระบบที่ยังเป็นต้นแบบว่าใช้งานจริง; ห้ามเพิ่มยอดผู้ใช้/สถิติ/คำสั่งมอบหมายเอง

## การอ่านสามระดับ
- One Page: เห็นตัวตนและประเด็นเด่นโดยเร็ว
- Three Pages: เห็นวิธีคิดและผลงานที่ขยายความ
- Full Book: หัวข้อทางราชการทั้งหมด + เนื้อหาเพิ่มเติม + ภาพและหลักฐาน
ทั้งสามผลิตจากข้อเท็จจริงร่วม ไม่ใช่คัดลอกสรุปซ้ำทั้งหน้า
