# Document Communication Blueprint — เล่มเต็ม ๒๕๖๙
**สถานะ:** Brainstorm baseline ไม่ใช่ข้อความรับรองอย่างเป็นทางการ

## 1. Audience
ผู้รับสารหลัก: ผู้บังคับบัญชาระดับสูง/ผู้ประเมินการแต่งตั้งให้ดำรงตำแหน่งสูงขึ้น มีเวลาจำกัด ความคุ้นเคยศัพท์เทคนิคแตกต่างกัน ต้องการความเหมาะสมกับตำแหน่ง ความน่าเชื่อถือ ผลงานและหลักฐาน สมมติฐานนี้ต้องปรับเมื่อทราบตำแหน่งเป้าหมายและแบบประเมินจริง

**การอ่านสองความเร็ว:** ภายใน 30–60 วินาทีแรกเห็นตัวตนและผลสัมฤทธิ์; อ่านละเอียดแล้วค้นหลักฐานย้อนหลังได้

## 2. Character
สุขุม สง่างาม เป็นทางการ จริงใจ มีเหตุผล เน้นประโยชน์ราชการ ไม่ขายโปรแกรม ไม่อวยตนเอง
สีหลัก Navy #122944; Gold #B28B48; Silver #A7B0BA; White. กราฟิกช่วยอ่าน ไม่แทนข้อเท็จจริง

## 3. Communication objectives
รับรู้: มีผลงานหลายด้านและภารกิจจริง
เข้าใจ: ปัญหา วิธีดำเนินงาน ผล และประโยชน์
เชื่อมั่น: บทบาทและหลักฐานตรงกัน
จดจำ: คิดวิเคราะห์ วางระบบ ลงมือแก้ปัญหา พัฒนาคน สื่อสารให้เข้าใจง่าย
เชื่อมอนาคต: เห็นแนวทางต่อยอดสู่ความรับผิดชอบสูงขึ้นอย่างระมัดระวัง

## 4. Master key message (ข้อเสนอ)
> คิดเป็นระบบ ลงมือแก้ปัญหาจริง สร้างผลสัมฤทธิ์ และนำความรู้ความสามารถไปสร้างประโยชน์แก่ราชการ

Supporting messages:
- ลดงานซ้ำและใช้ทรัพยากรคุ้มค่า
- จัดข้อมูลให้พร้อมติดตาม วางแผน และรายงาน
- สื่อสารเรื่องซับซ้อนให้ง่ายผ่าน One-page, Infographic, Poster, Presentation, LINE Sticker
- ถ่ายทอดความรู้และกำกับวินัยจริง
- ศึกษาต้นแบบและพัฒนาตนเอง โดยแยกแนวคิดออกจากผลจริง

## 5. Narrative throughout book
ภารกิจ/ปัญหา → วิธีคิด → สิ่งที่ข้าฯ ลงมือทำ → ผลที่ตรวจได้ → ประโยชน์ → แนวทางต่อยอด → หลักฐาน
ให้แต่ละบทอยู่ภายใต้หัวข้อบังคับ ไม่ย้าย/เปลี่ยนหัวข้อบังคับเพื่อให้เข้ากับเรื่องเล่า
เปิดบทด้วยใจความหนึ่งประโยค; มีกรณีตัวอย่าง; ปิดด้วยประโยชน์ต่อหน่วยงานที่พิสูจน์ได้
เริ่มอธิบายไทยทั่วไป แล้วตามด้วยศัพท์เทคนิคในวงเล็บ เช่น ระบบแสดงข้อมูลภาพรวม (Dashboard), โปรแกรมช่วยทำงานซ้ำ (Macro), ระบบตอบกลับข้อมูลผ่านไลน์ (LINE Bot)

## 6. Policy alignment
อธิบายความสอดคล้องที่ตรวจสอบได้กับแนวทางบริหารของสำนักงานตำรวจแห่งชาติ โดยอ้างอิงนโยบายฉบับทางการและตรวจข้อ/วันที่ก่อนเผยแพร่
**ห้าม** อ้างว่าผลงานก่อนประกาศนโยบายปีงบประมาณ ๒๕๗๐ ได้ทำตามคำสั่งนโยบายนั้น ให้ใช้ “มีลักษณะสอดคล้องกับทิศทาง” หรือ “สามารถนำไปต่อยอดสนับสนุน”
การอ้างเลขข้อ/ข้อความนโยบายยัง PENDING PRIMARY POLICY PDF VERIFICATION

## 7. Visual strategy
หน้าเปิดบท: สรุปภารกิจ + key message + ภาพ/แผนภาพที่อ้างหลักฐาน
หน้าผลงาน: มีความต่างระหว่างภาพหลักฐานจริง (ต้องใส่ที่มา) กับภาพประกอบแนวคิด (ต้องระบุ)
กลุ่ม LINE Sticker และสื่อองค์กรใช้ตัวอย่างภาพจริงพร้อมอธิบายวัตถุประสงค์และประโยชน์ที่ยืนยันได้ ไม่อ้างยอดผู้ใช้
ใช้ภาพหน้าจอจาก Google Drive เป็นหลักฐาน/แรงบันดาลใจ แต่อย่าสร้าง dashboard จำลองแล้วแสดงเสมือนภาพจริง

## 8. Governance
ทุก claim มี evidence ID, source URL/path, status: ยืนยันหลักฐาน / เจ้าของยืนยัน / ศึกษา-ต้นแบบ / แนวทางต่อยอด / รอตรวจ
คำกล่าวอ้างต้องผ่าน legal, personal-data, policy-date, Thai proofreading, and evidence gate ก่อน FINAL

## Audit v2 — executive narrative controls (2026-10-17)
- เพิ่มเป้าหมายระดับ ๕: ผู้อ่านใช้ผลงาน/หลักฐานประกอบการประเมินความพร้อมในการรับหน้าที่สูงขึ้นเอง ไม่ชี้นำว่าต้องประเมินว่าเหมาะสม
- แยกผู้รับสาร ๓ แบบ: ผู้บริหารอ่านเร็ว / ผู้ประเมินตรวจรายละเอียด / ผู้ประสานงานค้นหลักฐาน
- ระวังภาพจำว่าเป็นแฟ้มโปรแกรม IT: ให้แสดงหน้าที่ ความรับผิดชอบ การทำงานกับคน และประโยชน์ต่อราชการเทียบเคียงกับผลจากเทคโนโลยี
- แยกกรณีศึกษาเป็นเจ้าของรายละเอียดหนึ่งบท และ cross-reference เมื่อปรากฏบทอื่น
- แยกภาพหน้าจอจริงกับกราฟิกอธิบาย; หน้าเนื้อหาพื้นขาวเพื่ออ่านง่าย ไม่ใช้ทองเข้มทั้งเล่ม
- ความสามารถที่ยืนยันใหม่: Microsoft Office/Excel/Macro; LINE Bot เพื่อสื่อสาร/รับฟังความคิดเห็น; AI สร้าง Infographic/One Page/Poster; สร้าง LINE Sticker. ตัวอย่างระบบ LINE Official ไม่ใช่หลักฐานว่าได้เปิดบริการทุกเมนูแล้ว
