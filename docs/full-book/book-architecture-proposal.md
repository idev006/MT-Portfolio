# Book Architecture — เสนออนุมัติ ก่อนสร้าง Word
สถานะ **PROPOSED / ยังไม่ล็อกสารบัญ**; วันจัดทำ 17 ตุลาคม 2569

## หลักคิด
“หนังสือแสดงความเหมาะสมต่อความรับผิดชอบสูงขึ้น โดยมีผลงานและหลักฐานเป็นเครื่องพิสูจน์”
**หัวข้อบังคับ Word เก่า ๑–๑๓ ห้ามหาย**: ฉบับปรับโครงสร้างนำมาเป็นข้อมูลหลัก แต่ถ้อยคำหัวข้อบังคับเดิมต้องรักษาหรือแสดง crosswalk อย่างชัดเจนจนมีแบบประเมินทางการยืนยันรูปแบบอื่น

## ส่วนต้น (ไม่นับเป็นหัวข้อบังคับ)
A. ปกหน้า — ชื่อเรื่อง/ตำแหน่ง/ปี
B. One-page executive profile — ภาพรวม (ไม่ต้องซ้ำบทสรุป ๓ หน้า)
C. คำนำ — วัตถุประสงค์และขอบเขตข้อเท็จจริง
D. สารบัญ — Word Heading styles ใช้สร้างอัตโนมัติ
E. Executive synthesis (อาจเลือกแทรก Three Pages ฉบับตรวจทานแล้ว) — สรุปปัญหา การดำเนินงาน ผล และองค์ประกอบความพร้อม ไม่ใช่โฆษณา

## ส่วนที่ ๑ — คุณสมบัติและประสบการณ์ [บังคับ ๑–๔]
๑ คุณวุฒิการศึกษา
๒ หลักสูตรการฝึกหรือศึกษาอบรม (ถ้ามี)
๓ ความรู้ ความสามารถ [รวม Excel/Macro, LINE Bot, AI สื่อ, LINE Sticker; อธิบายไทยก่อน]
๔ ประวัติการดำรงตำแหน่ง
**สารที่ผู้อ่านควรได้รับ:** มีพื้นฐานและประสบการณ์ที่นำมาใช้ทำงานจริง

## ส่วนที่ ๒ — ผลงาน ภารกิจ และความรับผิดชอบ [บังคับ ๕–๙]
๕ ผลงานดีเด่นเป็นที่ประจักษ์หรือได้รับประกาศเกียรติคุณ (ระดับ ตร., บช., บก., กก.)
๖ ภารกิจพิเศษนอกเหนือจากภารกิจตามหน้าที่รับผิดชอบ (ระดับ ตร., บช., บก., กก.)
๗ ภารกิจตามหน้าที่รับผิดชอบ
๘ อื่นๆ (ถ้ามี) — งานริเริ่ม/สนับสนุนข้ามฝ่าย/ต้นแบบ เมื่อเข้าเกณฑ์และไม่ซ้ำรายการอื่น
๙ ใบประกาศนียบัตร
**สาร:** ทำงานจริง มีผลให้เห็น ตรวจสอบบทบาทและหลักฐานได้
ต้องมีแหล่งบ้านหลักของแต่ละผลงานเพียงหนึ่งบท การกล่าวถึงบทอื่นให้เป็น cross-reference

## ส่วนที่ ๓ — การมีส่วนร่วมในองค์กร สังคม และความพร้อม [บังคับ ๑๐–๑๓]
หน้าเปิดหมวดร่วม (ไม่เปลี่ยนเลขบังคับ)
๑๐ การเข้าร่วมกิจกรรมจิตอาสา
๑๑ การมีมนุษยสัมพันธ์กับเพื่อนร่วมงาน
๑๒ การเข้าร่วมกิจกรรมและงานพิธีต่างๆ
๑๓ การออกกำลังกายและดูแลสุขภาพ
**สาร:** มีส่วนร่วมตามหลักฐานและใส่ใจความพร้อมในการปฏิบัติหน้าที่
จาก readme.txt: ภาพกำชับวินัยให้อยู่หมวดหน้าที่/บุคลากร, การตรวจศูนย์ ๑๙๑ อยู่ภารกิจ, ภาพเครื่องเสียงอยู่ภารกิจ IT ไม่จัดเป็นกิจกรรมเพื่อเพิ่มปริมาณ
ไม่มีภาพการออกกำลังกายใน readme.txt ที่ตรวจ จึงต้องหาหลักฐานอื่น ไม่แต่งข้อมูล

## ส่วนท้าย
บทสรุปเชิงหลักฐาน (ไม่สรรเสริญตนเอง) → ภาคผนวกผลงาน/คำสั่ง/หลักฐาน/ภาพจริง → อภิธานศัพท์เฉพาะที่จำเป็น → แหล่งข้อมูล
ไม่เผยแพร่ข้อมูลส่วนบุคคลเกินความจำเป็น
นโยบาย ผบ.ตร. เชื่อมเฉพาะในบทที่เกี่ยวข้อง เมื่อได้แหล่งทางการและลำดับเวลาถูกต้อง

## รูปแบบหน้ามาตรฐาน
- Profile / opening: อ่านเร็ว
- Case study / performance: ปัญหา → วิธีทำ → ผล → ประโยชน์; screenshot พร้อม caption/แหล่ง
- Duty / administration: บทบาท ช่วงเวลา ผลงานตามงานจริง
- Activity: 1 กิจกรรม = 1 เหตุการณ์ ไม่ใช่จำนวนภาพ; คำอธิบายสั้นและวันที่
- Appendix / evidence: เลขหลักฐาน ลิงก์/QR เฉพาะเมื่อผ่านการตรวจความปลอดภัย

## Open decisions ก่อน LOCK
1. ตำแหน่งเป้าหมายและแบบ/คำสั่งที่กำหนดถ้อยคำหรือหน้าตาหัวข้อ
2. ชื่อหัวข้อ ๓, ๕, ๖, ๘ ที่แตกต่างกันใน Word สองฉบับ — ใช้หัวข้อบังคับเก่าเป็น baseline ปลอดภัย
3. Three Pages จะรวมทั้งชุดหน้าต้นหรือสรุปใหม่ไม่ซ้ำ One Page
4. ข้อความตัวเลขและภาพหลักฐานที่ยังต้องรับรอง
5. ข้อมูลสุขภาพ/ภาพกิจกรรมที่ยังไม่มีหลักฐานในชุดปัจจุบัน


## Owner directive — 2026-10-17: จัดกลุ่มเฉพาะหัวข้อ ๑๐–๑๒
**ข้อกำหนดล่าสุด (เหนือข้อเสนอเก่า):** ให้มีหัวข้อครอบ **“การเข้าร่วมกิจกรรม”** สำหรับหัวข้อบังคับ **๑๐ การเข้าร่วมกิจกรรมจิตอาสา, ๑๑ การมีมนุษยสัมพันธ์กับเพื่อนร่วมงาน, ๑๒ การเข้าร่วมกิจกรรมและงานพิธีต่างๆ** เท่านั้น และ **หัวข้อ ๑๓ การออกกำลังกายและดูแลสุขภาพต้องแยกเป็นหัวข้อหลักตามเดิม**. ห้ามรวม ๑๓ ไว้ในหมวดกิจกรรมดังข้อเสนอเก่าที่ถูกยกเลิก.

หัวข้อย่อยเชิงประเภทกิจกรรมอ้างจากภาพจริงและ `readme.txt` ใน Google Drive `/2569/ภาพกิจกรรม`: (ก) จิตอาสา/ช่วยเหลือสังคม (ข) พัฒนาสภาพแวดล้อมและกิจกรรมหน่วย (ค) งานพิธีการ (ง) สานสัมพันธ์องค์กร (จ) ประชาคม/ชุมชน. ต้องมี mapping กลับสู่ข้อบังคับ ๑๐–๑๒ อย่างชัดเจน และตรวจว่าเหตุการณ์เดียวหลายภาพไม่ถูกนับซ้ำ. รูปกำชับวินัย ตรวจศูนย์ ๑๙๑ และติดตั้งโสตฯ เป็นภาพภารกิจ ไม่จัดเป็นกิจกรรมทั่วไป.
