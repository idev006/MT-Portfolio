# Production Readiness Gates — before Word Master
สถานะ: ตรวจได้แบบ PASS/PENDING/BLOCKED เท่านั้น **ไม่ใช่ผลการประเมินตำแหน่ง**

| Gate | เกณฑ์ PASS | สถานะ 2026-10-17 |
|---|---|---|
| G1 Audience | วิเคราะห์ผู้บริหาร ผู้ตรวจ และวิธีอ่าน/เป้าหมาย; ขอบเขตตำแหน่งชัด | PENDING: ยังไม่ทราบเกณฑ์เฉพาะตำแหน่ง |
| G2 Book structure | หัวข้อ Word ๑–๑๓ ครบและ crosswalk ชื่อ; ลำดับได้รับการรับรอง | PENDING: มีโครงเสนอ ยังไม่ล็อก |
| G3 Message | key message รายบทชัด มีหลักฐานตั้งต้น; ไม่มีคำเกินจริง | PENDING: ทำแผนที่แล้ว รอทวน claim |
| G4 Evidence | ข้ออ้างหลักมีแหล่งและสถานะ; ภาพตรวจจริง; sensitive data จัดการ | PENDING: ยังไม่ตรวจครบ |
| G5 Word design | A4, styles, headers/footers, picture placement, captions, references, Thai proofreading QA | PENDING: ยังไม่ได้สร้าง Master Template |

**ไม่เริ่มฉบับสมบูรณ์ก่อน Gate ครบ** แต่สร้างต้นแบบหน้าเพื่อทดสอบรูปแบบได้หลังได้รับความเห็นชอบโดยไม่อ้างว่า final

## Preflight ฉบับย่อ
- [ ] หัวข้อบังคับครบ ไม่มีกรณีสลับชื่อแล้วหาย
- [ ] ไม่เอาคำอธิบาย screenshot มาแทน evidence ว่าประหยัดเวลาจริง
- [ ] มีผู้รับรองตัวเลขและช่วงเวลาที่กล่าวอ้าง
- [ ] ๑๙๑ รายงานประจำวัน แยกจาก dashboard
- [ ] สื่อองค์กร (LINE Sticker, poster, infographic, one-page, presentation) รวมในรายการผลงาน
- [ ] LINE Bot รู้ข้อจำกัดว่าเป็นความสามารถหรือระบบที่มีการใช้จริง
- [ ] AI CCTV/Computer Vision prototype ไม่อ้างใช้จริง
- [ ] ภาพจริงไม่ถูกสร้างใหม่เป็น screenshot หลักฐานปลอม
- [ ] ไม่แก้เอกสารต้นฉบับ Google Drive ใด ๆ
- [ ] Review โดยเจ้าของก่อนประกาศ FINAL
