# Mandatory Heading Crosswalk — ห้ามหัวข้อสูญหาย
**ฐาน:** Word สองฉบับจาก Drive/2569; ผู้ใช้ยืนยันว่าเป็นหัวข้อบังคับ
**ข้อตกลง:** ใช้ฉบับปรับโครงสร้างเป็นต้นฉบับโครงเรื่อง แต่ต้องรักษาสาระบังคับเดิม; ไม่ตีความการรวมหมวดกิจกรรมว่าได้รับอนุญาตให้ลบชื่อหัวข้อบังคับ

| หมวดฉบับเก่า | หัวข้อเดิม | การวางในเล่มใหม่ / ข้อควบคุม |
|---|---|---|
| ๑ | คุณวุฒิการศึกษา | คงครบ |
| ๒ | หลักสูตรการฝึกหรือศึกษาอบรม (ถ้ามี) | คงครบ; ตรวจเลขย่อยผิดพิมพ์ ๒๕. |
| ๓ | ความรู้ ความสามารถ | ฉบับใหม่ขยาย “และการประยุกต์ใช้เพื่อพัฒนางาน”; Microsoft Office/Excel/Macro, LINE Bot, AI Graphic, LINE Sticker ต้องไม่ตกหล่น |
| ๔ | ประวัติการดำรงตำแหน่ง | คงครบ ตรวจคำสั่งต้นฉบับ |
| ๕ | ผลงานดีเด่นเป็นที่ประจักษ์หรือได้รับประกาศเกียรติคุณ (ระดับ ตร., บช., บก., กก.) | ชื่อบังคับเดิม/เทียบกับฉบับใหม่ “ผลงานเด่นและผลสัมฤทธิ์เชิงประจักษ์” ต้องตกลงชื่ออย่างเป็นทางการก่อนล็อกสารบัญ |
| ๖ | ภารกิจพิเศษนอกเหนือจากภารกิจตามหน้าที่รับผิดชอบ (ระดับ ตร., บช., บก., กก.) | ชื่อบังคับเดิม/เทียบกับฉบับใหม่ “ภารกิจพิเศษและการแก้ปัญหางานด้วยข้อมูลและเทคโนโลยี” |
| ๗ | ภารกิจตามหน้าที่รับผิดชอบ | คงครบ รวม AV ประชุม ๑๙๑ ตามบทบาทที่ยืนยัน |
| ๘ | อื่นๆ (ถ้ามี) | ฉบับใหม่เป็น “การริเริ่มพัฒนางานและการสนับสนุนหน่วยอื่น”; รักษาสาระหมวดอื่น ๆ |
| ๙ | ใบประกาศนียบัตร | คงไว้หรือลงหัวข้อย่อยที่ยังค้นพบได้; ตรวจประกาศตัวจริง |
| ๑๐ | การเข้าร่วมกิจกรรมจิตอาสา | อยู่ในหมวดครอบกิจกรรม พร้อมชื่อหัวข้อย่อยเดิม |
| ๑๑ | การมีมนุษยสัมพันธ์กับเพื่อนร่วมงาน | อยู่ในหมวดครอบกิจกรรม พร้อมชื่อหัวข้อย่อยเดิม |
| ๑๒ | การเข้าร่วมกิจกรรมและงานพิธีต่างๆ | อยู่ในหมวดครอบกิจกรรม พร้อมชื่อหัวข้อย่อยเดิม |
| ๑๓ | การออกกำลังกายและดูแลสุขภาพ | อยู่ในหมวดครอบกิจกรรม พร้อมชื่อหัวข้อย่อยเดิม |

**ข้อเสนอสำหรับหัวข้อครอบ ๑๐–๑๓:** “การมีส่วนร่วมในกิจกรรมองค์กร สังคม และการเสริมสร้างความพร้อมในการปฏิบัติราชการ” โดยคงการจับคู่รายการเดิมให้ครบ และเปิดเผยจุดอ้างอิงในสารบัญ (ต้องตรวจข้อกำหนดเลขหมวดก่อนเปลี่ยนจริง)

**หมายเหตุ:** ฉบับปรับโครงสร้างมีหัวข้อที่ตรวจจับเลขหลักชัด ๑–๘ และมีเนื้อหาต่อท้าย ควรอ่าน DOCX เชิงโครงสร้าง/แบบราชการต้นฉบับก่อนรับรองว่าส่วน ๙–๑๓ ถูกตั้งเลขอย่างไร; ไม่สรุปเองว่าหัวข้อบังคับหายไป
