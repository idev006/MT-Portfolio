## Rejected drafts: objective critique
- Flat, repeated white rectangles, thin gold bars, large meaningless empty space, weak hierarchy and few real visual explanations.
- Overemphasis on architecture in header vs real performance evidence.
- No purposeful case-specific diagrams or credible image hierarchy; no differentiation between primary and secondary achievements.
- Earlier outputs labeled production despite not meeting professional standards.
- A generated horizontal triptych was **especially unsafe**: fictitious officer portrait, fabricated scenes/award imagery/dashboard interfaces, fictitious 50–100% percentages and corrupted Thai. Do not split/crop or reuse it.

## Recommended production composition
- P1: strong executive identity section, **empty 4:3 portrait slot**, compact approach process, two dominant verified metric stories. Make metrics visibly large and precise; “ประมาณ ๑ ชั่วโมง → ไม่เกิน ๑ นาที” and “มากกว่า ๒๐๐ หน้า / ไม่เกิน ๑ นาที”.
- P2: differentiated editorial mosaic of five actual cases, with a grounded schematic/icon for each; emphasize data→report→decision rather than fake system UI. Prior-unit attribution visibly correct.
- P3: distinguish **actual leadership actions** from **management concepts** using separate treatments; then prototype, continuous learning, awards. Do not fabricate certificate graphics or faces.
- Every graphic must communicate a fact already in content-lock; avoid invented flows, accuracy rates, deployment indicators, counts, budget savings or impact percentages.
- Use a consistent master grid but vary card sizes and case hierarchy. Check that text can be read on printed A4.
- If no verified real case imagery is available, create precise **non-evidentiary** line diagrams or icons instead of fake screenshots.
- Reserve official signature area only if required by verified submission rules; no invented signatures.

## Mandatory QA gates
1. **Copy audit**: compare every page item and exact titles to content-lock; zero fabricated claims, no omissions or wrong status.
2. **Thai audit**: font shaping, every Thai diacritic, spelling, official rank/title, Thai numerals, no clipped glyphs or text.
3. **Image authenticity**: verified owner assets only as photographic evidence; synthetic conceptual images marked and not confused with evidence; no artificial portrait, award, police incident, or dashboard.
4. **Visual art direction**: hierarchy, meaningful infographic graphics, visual balance, intentional use of whitespace, no empty-card draft look.
5. **Print/export**: 3 independent A4 portrait raster images; >=2480×3508px, preferably 3508×4960px; real PDF and editable source when requested; file paths verified before linking.
6. **Compliance**: no logo, blank 4:3 portrait placeholder, no sensitive operational/personnel data exposed; awards verified with originals; explicit owner sign-off.
7. **Release labeling**: call **PRODUCTION CANDIDATE / FOR REVIEW** until all evidence, proofreading and owner gates pass. Never claim FINAL by default.
