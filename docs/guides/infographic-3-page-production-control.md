## ๑. ลำดับแหล่งข้อมูล (Source Priority)

๒. `docs/drafts/executive-summary-3-pages.md` — ต้นฉบับโครงเรื่องและสาระทั้งสามหน้า
๓. หลักฐานรายชิ้นใน `docs/evidence/` และเอกสาร/ภาพต้นฉบับที่ผู้จัดทำส่งให้ — ใช้ตรวจยืนยันข้อเท็จจริง
๔. คำชี้แจงแก้ไขล่าสุดของผู้จัดทำ — ใช้แก้ข้อเท็จจริงเฉพาะจุดที่ขัดกับ draft; ต้องทำเครื่องหมายรอตรวจหลักฐานหากยังไม่มีเอกสารรองรับ
๕. ภาพตัวอย่าง/ไวร์เฟรม — ใช้เป็นแนวทางจัดหน้าเท่านั้น ห้ามใช้ข้อความที่ AI วาดเป็นต้นฉบับ

หากแหล่งข้อมูลขัดกัน ให้หยุดตรวจทาน ไม่แต่งเติมเพื่อให้ดูสมบูรณ์

## ๒. กฎบังคับ (Hard Gates)
- จำนวน **๓ หน้า** แยกไฟล์ภาพ **A4 แนวตั้ง** ทุกหน้า เป้าหมาย ๒๔๘๐ × ๓๕๐๘ พิกเซล (๓๐๐ dpi) และ PDF รวมเมื่อจำเป็น
- ใช้เลขไทยทั้งหมดในข้อความที่เผยแพร่; ตรวจชื่อบุคคล ตำแหน่ง ชื่อหน่วยงาน วันเดือนปี และคำราชการทีละตัวอักษร
- ไม่ให้ Image Generation วาดข้อความภาษาไทยที่เป็นสาระสำคัญ; ใช้การจัดวางตัวอักษรจริงจากต้นฉบับที่ตรวจแล้ว (text-first typesetting)
- ห้ามสร้างโลโก้หรือเครื่องหมายราชการขึ้นเอง; เว้นกรอบเส้นประบางไม่มีพื้นหลังสำหรับแทรกโลโก้ภายหลัง
- หน้าแรกมีช่องภาพถ่ายทางการแนวตั้ง **สูง:กว้าง = ๔:๓**; ไม่ใส่บุคคลสมมติ
- หากใช้พระบรมรูป/รูปปั้นสมเด็จพระนเรศวรมหาราช ใช้จากภาพอ้างอิงที่ผู้จัดทำกำหนดเท่านั้น; ห้ามเปลี่ยนองค์/สร้างทดแทน
- ภาพอาคารหอประชุมดุรงควิบูลย์ใช้ได้จากภาพอ้างอิงที่ผู้จัดทำส่ง (กลางวัน/ยามเย็น) เท่านั้น; ภาพอาคารใช้เป็นบรรยากาศ ไม่อ้างว่าเป็นหลักฐานผลงาน
- ใช้หัวข้อ **ผลงานเด่น**; ไม่ใช้หมายเลขกำกับหัวข้อเนื้อหา ใช้ไอคอนสื่อความหมายที่สอดคล้องกัน
- สีหลักน้ำเงินกรมท่า ทอง เงิน และขาว; เน้นความสง่า น่าเชื่อถือ อ่านง่าย ไม่ใช้พื้นผิวโลหะเงามากจนบดบังตัวอักษร
- Header กระชับ เป้าหมายประมาณ ๑๐–๑๒% ของหน้า; เนื้อหาประมาณ ๘๐%; Footer ประมาณ ๓–๕% โดยปรับได้เพื่อความอ่านง่าย
- ใช้รูปแบบ **ปัญหา/ความต้องการ → สิ่งที่ทำ → ผลที่เกิดขึ้น → ประโยชน์ต่อหน่วยงาน**; ไม่มีตัวเลขหรือผลลัพธ์ที่ไม่ได้รับการยืนยัน
- งานทดลองต้องติดป้าย **ศึกษา/ต้นแบบ**; ห้ามเขียนว่าใช้งานจริงหรือมีประสิทธิภาพเชิงตัวเลขโดยไม่มีหลักฐาน
- แยกผลงานจากหน่วยเดิมกับผลงานหน่วยปัจจุบันชัดเจน
- เผื่อพื้นที่ลงชื่อ/รับรองในเอกสารราชการตามระเบียบที่ใช้จริง; ตรวจข้อกำหนดแบบอักษรและขนาดจากเอกสารทางการก่อนส่งยื่น

## ๓. โครงเรื่องล็อกตามเอกสาร
### หน้า ๑ — จากปัญหางานจริง สู่การพัฒนาวิธีทำงาน
- ชื่อ: **ร้อยตำรวจเอก จิรัฎฐ์ธรณ์ จิตศิริ** / ตำแหน่ง: **รอง สว.ฝอ.๖ บก.อก.ภ.๖** (ตรวจคำสะกดกับเอกสารต้นฉบับก่อนเผยแพร่)
- Key Message: **คิดวิเคราะห์ วางระบบ พัฒนาคน และใช้เทคโนโลยีอย่างเหมาะสม เพื่อให้งานรวดเร็ว เป็นระบบ และเกิดประโยชน์ต่อราชการ**
- ผลงานเด่น: Report ๑๙๑ Processor — เวลาจัดทำรายงานจากประมาณ ๑ ชั่วโมง เหลือไม่เกิน ๑ นาที (ตรวจหลักฐาน); ประมวลผลเอกสาร/ใบเสร็จสหกรณ์มากกว่า ๒๐๐ หน้าในไม่เกิน ๑ นาที (ตรวจหลักฐาน); Dashboard ๑๙๑ — เตรียมและจัดโครงสร้างข้อมูลเพื่อการติดตามและวิเคราะห์
- วิธีทำงาน: ปัญหา → วิเคราะห์ → วางระบบ → เลือกวิธี/เครื่องมือ → ดำเนินการ → ตรวจสอบ → ปรับปรุง
- สารจบหน้า: **เห็นปัญหา → คิดเป็นระบบ → ทำให้เกิดผล**

### หน้า ๒ — จากข้อมูลและระบบ สู่การกำกับและการตัดสินใจ
- **ระบบสายตรวจฉลามบก**: ผลงานช่วงปฏิบัติราชการที่กองบังคับการปราบปราม; ระบบติดตาม/ประเมินผลการออกตรวจของสายตรวจรถยนต์ตามที่มีหลักฐาน
- **IPB**: ผลงานจากหน่วยเดิม; Web Application จัดเก็บพิกัด/รายละเอียดสถานที่หรือวัตถุ แสดงบนแผนที่และเลือกเงื่อนไข เพื่อประกอบการวางแผนด้านการรักษาความปลอดภัย
- **Dashboard ๑๙๑**: เตรียมข้อมูล จัดโครงสร้าง แสดงผลเพื่อการติดตาม/วิเคราะห์
- **รายงานครุภัณฑ์วิทยุโทรคมนาคม**: นำข้อมูลที่มีอยู่มาประมวลผลและสรุปตามโจทย์ผู้บังคับบัญชา เช่น ยี่ห้อ รุ่น หน่วยที่ครอบครอง และจำนวน; **ไม่ได้พัฒนาฐานข้อมูลวิทยุ** และ **ห้ามอ้างการจำหน่ายครุภัณฑ์โดยไม่มีหลักฐาน**
- **สนับสนุนภารกิจ**: รายงาน One Page/Infographic/Presentation, IT, ภาพเสียง/การประชุม และร่วมตรวจประเมินศูนย์ ๑๙๑ ตามที่มีหลักฐาน
- สารจบหน้า: **เปลี่ยนข้อมูลและกระบวนงานให้เป็นเครื่องมือที่ผู้บังคับบัญชาใช้กำกับ วางแผน และตัดสินใจได้ง่ายขึ้น**

### หน้า ๓ — พัฒนางาน พัฒนาคน และพัฒนาตนเองอย่างต่อเนื่อง
- **พัฒนาคนและทีมงาน**: ชี้แจงเป้าหมาย แบ่งงาน สอนงาน ส่งเสริมการทำงานทดแทน และกำชับวินัย/จรรยาบรรณ
- **เรียนรู้และพัฒนางานใหม่**: MTSecurity / AI CCTV / Computer Vision **ศึกษา/ต้นแบบ**; Generative AI ทดลองประยุกต์ใช้ตามภารกิจ ไม่อ้างการใช้งานจริงเกินหลักฐาน
- **การพัฒนาตนเอง**: หลักสูตร AI/ML, Generative AI, AI Governance, Network/IoT, PDPA, Cyber Safety ตามเกียรติบัตรที่มี; ใบอบรมไม่ใช่ผลสัมฤทธิ์โดยลำพัง
- **คุณธรรม จริยธรรม และการได้รับการยอมรับ**:
  - ITA ปีงบประมาณ **๒๕๖๗**: ผู้ปฏิบัติงานดีเด่น ทำงานเชิงรุก ในการขับเคลื่อนการประเมินคุณธรรมและความโปร่งใสของสถานีตำรวจ ในตำรวจภูธรภาค ๖ (ตรวจข้อความตรงประกาศ)
  - สำนักงานตำรวจแห่งชาติ ปีงบประมาณ **๒๕๖๙**: **ข้าราชการตำรวจที่ประพฤติปฏิบัติดีเยี่ยม ตามประมวลจริยธรรมข้าราชการตำรวจและกฎ ก.ตร. ว่าด้วยจรรยาบรรณของตำรวจ** (หลักฐาน: `docs/evidence/police-hq-certificate-2569.md`)
- Closing: **ข้าฯ มุ่งพัฒนาความสามารถในการคิดวิเคราะห์ วางระบบ พัฒนาคนและกระบวนงาน ตลอดจนเลือกใช้ข้อมูล ความรู้ และเทคโนโลยีอย่างเหมาะสม เพื่อให้เกิดผลสัมฤทธิ์และประโยชน์ต่อหน่วยงานและทางราชการอย่างต่อเนื่อง**

## ๔. ขั้นตอนผลิต (Production Workflow)
๑. อ่าน SSOT, Draft, หลักฐาน และคำแก้ล่าสุดก่อนเริ่ม
๒. สร้าง **Content Matrix** รายการข้อความ/หน้า/หลักฐาน/สถานะตรวจแล้วหรือรอตรวจ
๓. ตรวจข้อความให้ตรงหลักฐาน; ถ้าหลักฐานไม่พอ ให้ลดระดับถ้อยคำหรือระบุรอตรวจ ห้ามเดา
๔. ล็อกข้อความ (Content Lock) ก่อนทำกราฟิก; งานกราฟิกห้ามเปลี่ยนความหมายหรือเติมคำอ้างใหม่
๕. จัดหน้าแบบ text-first ตาม Wireframe เวอร์ชัน ๑ โดยให้พื้นที่เนื้อหามากกว่า Header
๖. ใช้ภาพต้นฉบับที่อนุญาตเท่านั้น; ภาพประกอบไม่ใช่หลักฐานผลงาน
๗. ตรวจตัวสะกด/เลขไทย/กรอบรูป ๔:๓/โลโก้เส้นประ/สัดส่วน A4/ความอ่านง่ายที่ขนาดพิมพ์จริง
๘. ตรวจแบบคนอ่าน: อ่านจบสามหน้าแล้วเข้าใจปัญหา สิ่งที่ทำ และประโยชน์ ไม่สับสนต้นแบบกับผลงานจริง
๙. ส่งออก PNG แยกสามหน้า + PDF รวม + แหล่งแก้ไขข้อความได้; ตรวจภาพและ PDF หลังส่งออก
๑๐. หากพบข้อความผิด แก้ที่ต้นฉบับข้อความก่อนสร้างภาพใหม่ทุกครั้ง

## ๕. Quality Gates — ต้องผ่านก่อนระบุว่า Final
- **Accuracy:** ชื่อ/ตำแหน่ง/คำราชการ/ตัวเลข/ปี ถูกต้องทุกตัว; ไม่มีข้อความ AI เพี้ยน
- **Evidence:** ทุกข้ออ้างตรวจย้อนกลับได้; ไม่มีรูปจำลองอ้างเป็นหลักฐาน
- **Scope:** ไม่อ้างว่ามีฐานข้อมูลวิทยุ ไม่อ้างการจำหน่าย และแยก Prototype/หน่วยเดิม
- **Visual:** A4 แนวตั้งครบสามไฟล์; ตัวหนังสืออ่านได้จริง; Header ไม่แย่งพื้นที่; สี/ไอคอนสม่ำเสมอ
- **Assets:** กรอบโลโก้เส้นประ; ภาพถ่ายทางการ ๔:๓; รูปปั้น/อาคารใช้เฉพาะภาพอ้างอิงที่ได้รับ
- **Compliance:** ตรวจข้อกำหนดราชการเรื่องรูปแบบ การรับรอง และการส่งเอกสาร
- ถ้าไม่ผ่านข้อใดข้อหนึ่ง ให้ระบุ **DRAFT / NEEDS REVIEW** ห้ามติดป้าย Final

## ๖. Prompt สำหรับ AI ผู้ผลิตงาน
> จงสร้าง Infographic A4 แนวตั้ง ๓ หน้า แยกไฟล์ โดยอ่าน `docs/SSOT.md`, `docs/drafts/executive-summary-3-pages.md` และคู่มือฉบับนี้ก่อนทุกครั้ง ใช้เอกสารเป็นตัวนำ งานกราฟิกเป็นตัวสนับสนุน ตรวจทุกข้ออ้างกับหลักฐาน ไม่แต่งเติมผลลัพธ์ ใช้ตัวเลขไทยทั้งหมด จัดข้อความด้วยระบบ typesetting ที่แก้ไขได้ ไม่ให้ AI วาดตัวอักษรไทย เปลี่ยนหัวข้อหมายเลขเป็นไอคอน ลด Header ใช้สีทอง เงิน น้ำเงิน ขาว เว้นกรอบโลโก้เส้นประและช่องภาพทางการสูง:กว้าง ๔:๓ ใช้ภาพอ้างอิงที่ได้รับอนุญาตเท่านั้น ตรวจ Quality Gates ทุกข้อ และรายงานประเด็นที่ยังรอตรวจหลักฐานก่อนระบุว่างานเสร็จสมบูรณ์
