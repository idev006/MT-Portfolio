# MT-Portfolio — SSOT

## 1. Purpose

เอกสารนี้เป็นแหล่งอ้างอิงกลางสำหรับการตัดสินใจด้านโครงสร้าง เนื้อหา Personal Brand หลักฐาน และแนวทางการเขียน Portfolio ประจำปี พ.ศ. ๒๕๖๙

## 2. Brand Positioning

**Brand Core**

> คิดเป็นระบบ ออกแบบงานได้ ใช้ข้อมูลและเทคโนโลยีพัฒนาองค์กร

**Brand Interpretation**

ผู้รับการประเมินมีจุดเด่นด้านการคิดวิเคราะห์และออกแบบระบบงาน สามารถมองปัญหาจากการปฏิบัติงานจริง ออกแบบหรือปรับปรุงกระบวนงาน และเลือกใช้ข้อมูล ความรู้ และเทคโนโลยีที่เหมาะสมเพื่อเพิ่มประสิทธิภาพของหน่วยงาน

**สิ่งที่ไม่ควรทำ**
- ไม่สร้างภาพว่าเป็น “ผู้บริหารครบทุกด้าน” หากหลักฐานยังไม่รองรับ
- ไม่ทำให้ AI / Python / Dashboard / Computer Vision เป็นตัวแบรนด์
- ไม่ใช้ตัวเลขผลลัพธ์ที่ไม่มีหลักฐาน
- ไม่เรียกระบบต้นแบบว่าใช้งานจริง หากเป็นเพียงงานศึกษา/สาธิต

## 3. Narrative Standard

ใช้โครงสร้างมาตรฐาน:

**ปัญหา → สิ่งที่ดำเนินการ → ความท้าทาย → ผลลัพธ์/ประโยชน์ → แนวทางประยุกต์/ต่อยอด → หลักฐาน**

ผลลัพธ์มาก่อนเครื่องมือ และประโยชน์ต่อราชการมาก่อนรายละเอียดเชิงเทคนิค

## 4. Prototype Rule

ใช้ถ้อยคำ เช่น
- ศึกษาและพัฒนาระบบต้นแบบ
- ทดลองประยุกต์ใช้
- ใช้สำหรับศึกษาความเป็นไปได้
- สามารถศึกษาต่อยอดได้ตามความเหมาะสม

หลีกเลี่ยง:
- ใช้งานได้จริง
- แม่นยำ
- รองรับการใช้งานจริง
- ระบุตัวบุคคลได้อย่างถูกต้อง
เว้นแต่มีหลักฐานยืนยัน

## 5. Two Deliverables

### A. เล่มใหญ่ — ผลการปฏิบัติงาน
หน้าที่: **พิสูจน์**

ประกอบด้วยผลงาน ความรู้ความสามารถ ภารกิจ หลักฐาน ภาพหน้าจอ ใบประกาศ หนังสือคำสั่ง และภาคผนวก

### B. สรุปผลการปฏิบัติงานไม่เกิน ๓ หน้า
หน้าที่: **ทำให้เข้าใจคุณค่าและ Personal Brand อย่างรวดเร็ว**

หลักการ:
- อ่านได้ภายในไม่กี่นาที
- เห็น Brand และผลงานเด่นตั้งแต่หน้าแรก
- ทุกข้อความต้องมีหลักฐานรองรับในเล่มใหญ่
- ไม่อัดภาพหรือข้อความจนแน่น

## 6. Evidence Strategy

**เนื้อหาหลัก = สรุปคุณค่า**  
**ภาคผนวก = หลักฐานเต็ม**

ใบประกาศส่วนใหญ่ควรอยู่ภาคผนวก โดยในเนื้อหาหลักใช้ตารางสรุปหลักสูตร/สถาบัน/องค์ความรู้/การนำไปใช้

รางวัลหรือประกาศเกียรติคุณที่สะท้อน “ผลงานที่ได้รับการยอมรับ” อาจนำมาแสดงในเนื้อหาหลักได้

## 7. Supporting Dimension — People

แสดงเท่าที่มีหลักฐานจริง เช่น
- Brief งานก่อนปฏิบัติ
- Coaching ระหว่างปฏิบัติ
- อบรม/กำชับวินัย
- ถ่ายทอดการจัดทำ One Page Report

มิตินี้ใช้ช่วยให้ภาพไม่แคบเป็น “คนเก่งเทคนิค” แต่ไม่ขยายเกินข้อเท็จจริง

## 8. Soft Closing

บทสรุปต้องย้ำ Brand และคุณค่าต่อองค์กร โดยไม่เขียนเชิงขอเลื่อนตำแหน่งตรง ๆ

ประโยคแกน:

> ข้าพเจ้ามุ่งพัฒนาความสามารถในการคิดวิเคราะห์ วางระบบ พัฒนากระบวนงาน และเลือกใช้ข้อมูล ความรู้ และเทคโนโลยีอย่างเหมาะสม เพื่อให้เกิดผลสัมฤทธิ์และประโยชน์ต่อหน่วยงานและทางราชการอย่างต่อเนื่อง
